# ZIKR Quran corpus attribution

This directory contains the complete Uthmani Quran text snapshot used by the ZIKR reader.

**Source:** Tanzil Quran Text (Uthmani), Version 1.1  
**Source:** https://tanzil.net/download/  
**License:** Creative Commons Attribution 3.0

Tanzil permits verbatim copying and distribution of the provided Quran text with clear attribution and requires the text itself not be changed. The ZIKR application stores the source corpus verbatim and applies only presentation/layout behavior at render time.

Please retain this notice with the corpus and consult Tanzil for future source updates.
