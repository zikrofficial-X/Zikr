# ZIKR Android v1.1.14
Release tag: `v1.1.14`

إصدار Android جديد مبني من أحدث مصدر على `main`، ويضم إصلاحات الفيديو والتحقق من محتوى الأطفال التي وصلت إلى الفرع الرئيسي في 10 نوفمبر 2026.

## الإضافات والإصلاحات

- **إصلاح توليد الفيديو:** مواءمة موصلات Hugging Face Wan وLTX مع عقود Gradio الحالية، وإيقاف إعادة المحاولة بعد استنفاد حصة ZeroGPU، مع الاحتفاظ بتفاصيل أخطاء كل مزود.
  - [9b23ab5](https://github.com/zikrofficial-X/Zikr/commit/9b23ab57049e69bbd2be2524bd3618b2a2c13440)
- **استعادة بيانات محتوى الأطفال:** استرجاع تصنيف السلاسل والبيانات الوصفية من المصادر المنتقاة الموثوقة، وإعادة التحقق الآمن والمحدد لمحتوى QA القديم، مع إبقاء المعالجة التجريبية Dry Run افتراضيًا.
  - [8b9b3ca](https://github.com/zikrofficial-X/Zikr/commit/8b9b3ca705e662670974deac316cf6dc336409e8)
- **إصلاح تنفيذ الترحيل مرة واحدة:** تمرير علم التطبيق مباشرة إلى أداة TypeScript وإضافة اختبارات تمنع تمريرًا غير موثوق لعملية backfill.
  - [a1cc362](https://github.com/zikrofficial-X/Zikr/commit/a1cc3627982cd62af55144a7f8fd3285a0675db0)

## ملفات الإصدار المطلوبة

- `app-release.apk` — نسخة Android قابلة للتثبيت، موقعة.
- `app-release.aab` — حزمة Android App Bundle، موقعة.
- `SHA256SUMS` — بصمات الملفات.
- `release-metadata.json` — رقم النسخة وversionCode وهوية التطبيق وSDK وCommit المصدر وبصمات الملفات.

## ضوابط التوقيع والنشر

1. يُنشأ Tag مُعنون من Commit الرئيسي نفسه، ثم يُنشأ GitHub Release في حالة Draft.
2. ينفّذ CircleCI فحوص المصدر وبوابة Supabase ثم يبني APK وAAB باستخدام مفتاح التوقيع المحمي.
3. يتحقق الناشر من تطابق مصدر الملفات مع هدف الـTag، ومن توقيع APK وAAB والـManifest وبصمات SHA-256 وبيانات الإصدار.
4. لا يتحول الإصدار إلى Published قبل نجاح كل التحققات ووجود الملفات الأربعة في Release.
5. الـGit Tag مُعنون لكنه غير موقّع تشفيريًا بمفتاح GPG/SSH مملوك للمشروع؛ أما ملفات APK/AAB فيجب أن تكون موقعة بمفتاح Android المحمي. لا يتم وصف الـTag بأنه Signed ما لم يؤكد GitHub ذلك.

## التحقق النهائي

تُستكمل بيانات النشر الفعلية بعد اكتمال CircleCI وناشر GitHub؛ ولا تُسجّل أحجام الملفات أو بصماتها أو حالة النشر قبل قراءتها من الـRelease المنشور.
