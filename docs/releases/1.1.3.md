# ZIKR Android v1.1.3

إصدار موثق مبني من أحدث commit على الفرع `main` بعد اجتياز فحوصات الجودة والنشر.

## معلومات الإصدار
- Android version: `1.1.3`
- Android versionCode: `57`
- Application ID: `com.zikr.app`
- Target SDK: `36`
- Previous stable tag: `v1.1.2`
- Release tag: `v1.1.3`

## نطاق الإصدار
- تحسين قسم الأدمن وربط إجراءات التوليد المباشر بـ GitHub Actions.
- تحسين تنسيق النص العربي داخل الفيديو ومعالجة اتجاه الكتابة والمصدر والتلاشي.
- توحيد بيانات الإصدار بين Android وiOS والواجهة وملفات التحقق.
- تقليل تشغيلات CI غير الضرورية وتحسين جدولة عامل الفيديو.
- إصلاح فحص بيئة النشر ليقرأ بيئة التطوير المحلية عند التحقق.
- تحديث أسرار النشر الخاصة بتكاملات الفيديو والنشر الاجتماعي.

## معيار الاكتمال
لا يعتبر الإصدار منشورًا نهائيًا إلا بعد نجاح Quality Gate وSupabase Production Health وCircleCI وبناء Android والتحقق من metadata والتوقيع ورفع APK وAAB وSHA256SUMS وrelease-metadata.json.

## ملاحظات النشر
سيقوم workflow `Create Android Release Tag` بإنشاء `v1.1.3` وإنشاء GitHub Release مسودة فقط بعد دمج commit يحمل بادئة `[PRODUCTION RELEASE]`. يتم نشر الأصول بعد اجتياز بناء Android والتحققات المطلوبة؛ ولا يوجد مسار `-build` منفصل حتى لا يتكرر بناء Android.

## دليل الاختبارات
- `pnpm release:metadata`
- `pnpm deploy:check`
- `pnpm check`
- `git diff --check`
- فحوصات GitHub Actions وCircleCI بعد الدمج.
- اختبار واجهة الأدمن على الهاتف والوضع الداكن.
