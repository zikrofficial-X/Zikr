# ZIKR Android v1.1.12
Release tag: `v1.1.12`

إصدار جديد مبني من أحدث commit على الفرع `main`، ويتضمن تحسينات SmartLink المعلنة، توحيد توثيق النشر الاجتماعي، وإصلاحات توصيل روابط تنزيل Android من GitHub Releases فقط.

## الإضافات والتطويرات
- إضافة SmartLink معلن في الصفحات العامة المؤهلة مع منع ظهوره في الصفحات المقدسة أو غير المناسبة.

- تفعيل ونشر مسار النشر الاجتماعي الآلي مع توثيق حالته التشغيلية.

## الإصلاحات

- إصلاح استيرادات SmartLink المفقودة في خدمة بيانات الفيديو الوصفية.
- إزالة الاعتماد على Supabase لتقديم ملفات APK/AAB وروابط تحديث التطبيق؛ GitHub Releases هو المصدر canonical.
- تشديد التحقق من سلامة ملفات Android وتوافق الوسم وcommit المصدر قبل النشر.

## Release and signing contract

1. The annotated Git tag must resolve to the exact release commit.
2. The draft GitHub Release must exist before the tag publisher workflow runs.
3. CircleCI is the Android signing authority and must report `ci/circleci: android-rebuild` as successful.
4. The GitHub publisher verifies APK/AAB signatures, manifest, provenance, byte-for-byte SHA-256 checksums, and release metadata before publishing assets.
5. The release remains draft until all signed assets pass verification; published releases are immutable.
6. The Git tag signature is recorded separately from the Android artifact signatures and GitHub release attestation. This environment has no owner-managed GPG/SSH private key, so the tag must not be described as cryptographically signed unless GitHub verifies it as such.

## Verification commands

```bash
gh release verify v1.1.12
gh release verify-asset v1.1.12 ./app-release.apk
gh release verify-asset v1.1.12 ./app-release.aab
sha256sum -c SHA256SUMS
```
