# ZIKR Android v1.1.12
Release tag: `v1.1.12`

## Release and signing contract

1. The annotated Git tag must resolve to the exact release commit.
2. The draft GitHub Release must exist before the tag publisher workflow runs.
3. CircleCI is the Android signing authority and must report `ci/circleci: android-rebuild` as successful.
4. The GitHub publisher verifies APK/AAB signatures, manifest, provenance, byte-for-byte SHA-256 checksums, and release metadata before publishing assets.
5. The release remains draft until all signed assets pass verification; published releases are immutable.
6. CircleCI uploads the verified APK, AAB, `SHA256SUMS`, and `release-metadata.json` directly to the Draft GitHub Release. Android release binaries are not uploaded to or read from Supabase Storage.
7. The Git tag signature is recorded separately from the Android artifact signatures and GitHub release attestation. This environment has no owner-managed GPG/SSH private key, so the tag must not be described as cryptographically signed unless GitHub verifies it as such.
