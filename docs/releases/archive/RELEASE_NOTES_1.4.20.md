# ZIKR 1.4.20

## ملخص الإصدار

يعيد هذا الإصدار تنظيم لوحة إدارة منصة ذِكرٌ في تنقل موحد قابل للصلاحيات، ويزيل طبقات التنقل المتكررة التي كانت تعرض نفس الوظائف في الشريط الجانبي والشريط العلوي وقائمة المكتبة وقائمة الهاتف. كما يرفع إصدار تطبيق Android إلى `versionCode=51` و`versionName=1.4.20`.

## التغييرات

أصبحت لوحة الإدارة مقسمة إلى مجموعات تشغيل واضحة: مركز التشغيل، المحتوى والمراجعة، الوسائط والفيديو، النشر والتطبيق، والمستخدمون والإعدادات. تُبنى الروابط الظاهرة من صلاحيات الدور الحالي، لذلك لا تظهر صفحات غير مسموحة، وتستخدم نسخة الهاتف نفس مصدر الروابط بدل نسخة مكررة مستقلة. أضيفت حالات التنقل النشط و`aria-current` وتحسينات العرض على الشاشات الصغيرة.

تم الحفاظ على مسارات الإدارة الحالية وواجهات API وتدفقات OAuth وتوليد الفيديو والنشر الخارجي، ولم تُنفذ عمليات حذف للبيانات أو تغييرات مدمرة في قاعدة البيانات. جرى التحقق من مسار Google OAuth الأصلي، ويستخدم callback HTTPS وسيطًا ثم يعيد النتيجة إلى `com.zikr.app://auth/callback`، مع وجود intent filters في Android.

## القيد المتبقي قبل النشر العام

لم يوجد `android/keystore.properties` أو keystore إصدار مملوك للمشروع في المستودع/البيئة. لذلك لا يمكن تسمية APK release الحالي بأنه إصدار production موثق للتوزيع العام، ولا يجوز إنشاء مفتاح بديل فوق مفتاح التطبيق الحالي دون معرفة المفتاح الأصلي. كما أن فحص Play Store يتطلب `ANDROID_APP_LINKS_SHA256` الحقيقي لشهادة توقيع الإصدار. بعد توفير keystore الصحيح وبصمة الشهادة، يعاد بناء release وتوقيعه ثم استخراج checksum وإنشاء release عام.

فشل `pnpm mobile:release-check` في وضع متجر التطبيقات فقط بسبب غياب `ANDROID_APP_LINKS_SHA256` و`IOS_ASSOCIATED_DOMAIN_APP_ID`، بينما اجتاز الفحص العادي وفحص OAuth الأصلي.
