# ZIKR Android v1.1.15
Release tag: `v1.1.15`

## الإصلاحات والتغييرات

- إزالة تحميل إعلانات Monetag بالكامل من تطبيق Capacitor.
- نقل سكربتات Monetag وGoogle Funding Choices وGoogle Tag Manager إلى تشغيل الموقع فقط؛ يخرج التطبيق الأصلي قبل تحميل أي منها.
- إخفاء روابط Monetag SmartLink الترويجية من واجهات التطبيق والـFooter.
- فصل Service Worker الخاص بالتطبيق عن تكامل Monetag الخارجي مع الإبقاء على مكتبة القرآن والصوت دون اتصال والإشعارات.
- تنظيف صفحات HTML المخزنة مؤقتًا التي تحتوي على علامات إعلانية قديمة دون حذف بيانات الاستخدام دون اتصال.
- إضافة فحوصات CI تمنع إعادة إدخال إعلانات إلى إصدارات Android/iOS مستقبلًا.

## سياسة الإعلانات

- تطبيقات Android/iOS وملفات APK/AAB مبنية دون Monetag أو AdSense أو SmartLink أو وحدات إعلانية.
- إعلانات Monetag المعتمدة تبقى في صفحات الموقع فقط.
- لا يتطلب هذا الإصلاح ترحيلًا لقاعدة بيانات Supabase.
- ملفات APK/AAB النهائية لا تُعلن منشورة قبل نجاح البناء والتوقيع والتحقق من بصمات SHA-256 ورفعها إلى GitHub Release.
