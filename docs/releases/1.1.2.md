# ZIKR Android v1.1.2

إصدار رسمي مبني من الشجرة الكاملة الصحيحة للمشروع بعد الإصدار `v1.1.1`.

## معلومات الإصدار
- Android version: `1.1.2`
- Android versionCode: `56`
- Application ID: `com.zikr.app`
- Target SDK: `36`
- Previous stable tag: `v1.1.1`
- Release tag: `v1.1.2`

## نطاق الإصدار
- توحيد نسخة التطبيق الظاهرة للمستخدم مع Android release metadata.
- تشديد فحص release metadata على package/Android/iOS/footer/release notes.
- تحسين release manager لمنع اختلاف رقم النسخة الظاهر في Footer.
- تحديث مسار Android release ليقبل AAB verification بنتيجة `jarsigner` الفعلية ويطبع التشخيص عند الفشل.
- الحفاظ على كامل source tree للمشروع وعدم إسقاط أي ملفات أثناء إنشاء release commit.

## معيار الاكتمال
لا يعتبر الإصدار منشورًا نهائيًا إلا بعد:
1. نجاح Quality Gate.
2. نجاح Supabase Production Health.
3. نجاح CircleCI Android rebuild.
4. نجاح توقيع APK/AAB والتحقق من applicationId/versionName/targetSdk.
5. ظهور APK وAAB وSHA256SUMS داخل GitHub Release.
6. تحديث سجل الإصدار في Supabase إلى `published`.
