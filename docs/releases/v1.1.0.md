# ZIKR v1.1.0 Release Record

## Release identity

- Version: `1.1.0`
- Android versionCode: `54`
- Application ID: `com.zikr.app`
- Target SDK: `36`
- Canonical web origin: `https://zikrmediaofficial.vercel.app`
- Release tag: `v1.1.0`

## Included in this release

- Fixed the admin social publishing center so both failed and partial publishing items can be selected.
- Fixed retry controls so blocked Facebook items can be manually requeued after credentials are repaired.
- Preserved successful platform results to avoid duplicate republishing.
- Hardened the autonomous video worker and its Supabase runtime integration.
- Verified real FFmpeg video generation and Supabase video storage.
- Updated Gemini fallback configuration to an active model.
- Aligned Android and iOS release metadata with the same semantic version and build number.

## Release verification

The release pipeline must pass:

- project verification
- mobile readiness verification
- TypeScript check
- lint
- production web build
- Capacitor Android sync
- signed Android APK and AAB build
- APK signature verification
