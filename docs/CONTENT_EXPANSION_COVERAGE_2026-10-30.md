# تقرير تغطية توسعة محتوى ZIKR — 30 أكتوبر 2026

## نطاق العمل

تم إعداد توسعة تغطي مجموعات الموقع العامة ولوحة الإدارة المرتبطة بالمحتوى. أُجريت تغييرات واجهة ومكتبات ثابتة على فرع مستقل، كما أُعدّت migration قابلة لإعادة التشغيل لإضافة البيانات والمقترحات التحريرية. لا تُطبّق هذه migration تلقائيًا على Supabase الإنتاجي، ولا يجري نشر أي مادة دينية أو تاريخية أو مخصصة للأطفال دون المراجعة المطلوبة.

## صفحات لوحة الإدارة

- المحتوى، المكتبة، المعرفة، المصادر، التحرير، الأقسام: أُضيفت مسودات مقالات ومقترحات أوصاف مرتبطة بالمصادر؛ تبقى غير منشورة حتى الاعتماد.
- قصص الأنبياء والغزوات والفتوحات والعلماء والصحابة: مقترحات التوسعة محفوظة منفصلة عن الحقول العامة المنشورة.
- الأطفال والألعاب: مقترحات وصف وأهداف مع اشتراط مراجعة ولي الأمر/المعلم.
- الفيديوهات والنشر الاجتماعي: لم تُنشأ سجلات فيديو أو معرفات منصات أو روابط غير موجودة.
- الاستوديو، الأتمتة، الجدولة، النشر، المهام: صفحات تشغيلية لا ينبغي ملؤها بسجلات محتوى تجريبية؛ لم تتغير مفاتيح التشغيل أو إعدادات النشر أو workers.
- المستخدمون، الأمان، السجل، النظام، SEO والإعدادات: صفحات إدارية ووظيفية؛ لم تتغير الصلاحيات أو الأسرار أو بيانات المستخدمين.

## قواعد الدقة والسلامة

1. لا يُعاد توليد نص القرآن أو استبداله؛ الأدعية الجديدة تُقرأ من جداول الآيات الأصلية.
2. لا يُنسب نص إلى النبي ﷺ إلا مع رابط مصدر واضح، وتظل العناصر الحديثية الجديدة مسودات حتى مطابقة النص والدرجة محليًا.
3. أوصاف الشخصيات التاريخية والأحداث والألعاب والتواشيح المقترحة محفوظة في حقول metadata للمراجعة، لا تستبدل النسخ المنشورة.
4. قصص الأطفال الجديدة مخفية افتراضيًا، ولا تحتوي صورًا أو صوتًا أو روابط خارجية، وتتطلب مراجعة ولي الأمر/المعلم.
5. لا تُخترع روابط فيديو أو بث أو ملفات صوتية أو أرقام أحداث.
6. لا تُكرر صفحات أو ألعاب أو مستويات موجودة؛ التوسعة تستخدم السجلات والأنظمة الحالية.
7. توجد فجوة ترجمة: 1,080 من أصل 1,170 هدف مستوى لعبة لا تملك ترجمة إنجليزية. تُسجل للفريق كعمل ترجمة مستقل ولا تُملأ بترجمة آلية غير مراجعة.
